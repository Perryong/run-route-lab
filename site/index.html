YOUR RUNNING ATLAS

Bring your runs to life.

Garmin authentication happens on your computer. This public page never asks for your password.

  1. Download the source project and install its Python requirements.
  2. Run python -m scripts.auth --repo OWNER/REPO locally to connect Garmin and set your repository secrets.
  3. Enable GitHub Pages with GitHub Actions, then set GARMIN_SYNC_ENABLED=true in repository variables.

Prefer export files? Use python -m scripts.import_exports imports/run.fit and publish the processed dataset. Full setup instructions are in the project README.

Only publish routes you want to share. Endpoint trimming reduces detail around your start and finish; it does not make a public route private.
